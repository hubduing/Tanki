# Формат уровня

Уровень — JSON-файл в `public/levels/`. Добавление или правка уровня не требует пересборки. Полное описание — PLAN.md, приложение А.

## Поля

| Поле | Тип | Правило |
|---|---|---|
| `number` | целое | от 1 |
| `palette` | целое | от 0, номер палитры фона |
| `spawnIntervalSec` | число | больше 0, задержка между появлениями врагов |
| `enemies` | массив строк | ровно 20 кодов: `B`, `F`, `P`, `A` |
| `player` | `{x, y}` | обязательна; координаты левого верхнего тайла танка |
| `enemySpawns` | массив `{x, y}` | минимум одна точка |
| `map` | массив строк | ровно 13 строк по 13 символов |

## Символы сетки

| Символ | Значение | Проходимость для танка |
|---|---|---|
| `.` | пусто | да |
| `#` | кирпич | нет, разрушается поквадрантно |
| `@` | сталь | нет |
| `~` | вода | нет |
| `*` | лес | да, рисуется поверх |
| `=` | лёд | да, скольжение |
| `E` | база | нет; ровно 4 клетки, квадрат 2×2 |

Позиция базы в метаданных не задаётся — она берётся из сетки.

## Проверка

- `pnpm check:levels` — валидирует все файлы `public/levels/*.json`.
- `pnpm test` — полный набор тестов, включая разбор и валидацию.

Валидатор: `src/levels/validate.ts`. Ошибки выводятся списком с указанием строки, столбца или поля.
