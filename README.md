# Танчики

Браузерная игра в духе классических «Танчиков». Полное описание — в [PLAN.md](PLAN.md).

## Требования

- Node.js 20+ и pnpm

## Команды

```bash
pnpm install       # установка зависимостей
pnpm dev           # дев-сервер на http://127.0.0.1:5173
pnpm build         # проверка типов + сборка в dist/
pnpm preview       # просмотр собранной версии
pnpm typecheck     # только проверка типов
pnpm test          # юнит-тесты (Vitest)
```

## Управление

- F3 — показать/скрыть счётчик FPS (отладка).

Игровое управление появится на этапе M1.

## Статус

Этап M0 (каркас) выполнен: TypeScript, Vite, Vitest, canvas 256×224 с целочисленным масштабированием.
