# Танчики

Браузерная игра в духе классических «Танчиков»: один игрок защищает базу от волн врагов.
Полное описание, архитектура и план — в [PLAN.md](PLAN.md), [docs/architecture.md](docs/architecture.md)
и [docs/level-format.md](docs/level-format.md).

## Требования

- Node.js 20+ и pnpm

## Команды

```bash
pnpm install       # установка зависимостей
pnpm dev           # дев-сервер на http://127.0.0.1:5173
pnpm build         # проверка типов + сборка в dist/
pnpm preview       # просмотр собранной версии
pnpm typecheck     # только проверка типов
pnpm test          # юнит-тесты и симуляции (Vitest)
pnpm check:levels  # валидация всех встроенных уровней
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки или WASD | Движение танка |
| Пробел или J | Огонь |
| Esc или P | Пауза (в паузе — «продолжить») |
| Enter | Старт из меню, подтверждение на экранах итогов |
| M | Выход в меню (из паузы) |
| N | Переключатель звука (в меню) |
| F3 | Оверлей отладки: состояние, шаги, кадры, FPS |

В начале уровня управление показывается подсказкой на несколько секунд.

## Что есть в игре

- 35 уровней, описанных данными в `public/levels/*.json`; добавление уровня не требует правки кода.
- Четыре типа врагов (`B`, `F`, `P`, `A`), лимит 4 врага на поле, спавн из очереди уровня.
- Шесть бонусов: звезда, граната, каска, лопата, танк, таймер.
- Тайлы: кирпич (разрушается поквадрантно), сталь, вода, лес, лёд, база-орёл.
- Процедурная графика и звук: спрайты и музыка синтезируются кодом, без внешних ассетов.
- Сохранение прогресса, рекорда и настройки звука в `localStorage`.
